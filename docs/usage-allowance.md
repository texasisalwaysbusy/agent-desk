# Usage allowances / 额度栏

![Current bilingual allowance preview](assets/allowance-preview.png)

The native sidebar displays remaining 5-hour and weekly percentages with reset countdowns. Length represents the remaining allowance; the whole fill shares one state hue. A continuous OKLab curve moves from water blue through cyan and a broad healthy green range, then orange and deep red. Static vertical shading and subtle highlights add glass depth without animation or a horizontal rainbow. Light and dark themes use the same state semantics.

原生侧栏显示 5 小时、每周剩余比例与重置倒计时。长度表示剩余量，整段填充共用一个状态主色。连续 OKLab 曲线从水蓝、青色进入较宽的健康绿色区，再转橙色与深红；静态垂直明暗和柔和高光形成玻璃厚度，没有横向彩虹或动态特效。明暗主题保持相同的状态语义。

Only an allow-listed display snapshot is forwarded from the official usage-limit response. The card does not receive raw account responses, identifiers, tokens, cash balances or conversations. A validated sidebar anchor is required; settings or ambiguous layouts park the card rather than floating it over content. Not every future Codex layout is guaranteed compatible.

额度栏只接收官方使用限额响应中白名单化的展示快照，不接收原始账户响应、账户标识、令牌、现金余额或对话。展示依赖已验证侧栏锚点；设置页或无法确认的布局会停放组件，不浮在内容上方。未来所有 Codex 布局不保证兼容。
